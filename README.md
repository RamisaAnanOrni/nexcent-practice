# Furniture Landing Page

A modern and responsive furniture landing page built using **React.js** and **Tailwind CSS**.  
This project focuses on clean UI design, reusable components, and responsive layouts.

## Features
- Responsive landing page design
- Modern UI with Tailwind CSS
- Reusable React components
- Hero section with call-to-action
- Product showcase section
- Clean and minimal layout

## Tech Stack
- React.js
- Tailwind CSS
- JavaScript (ES6)
